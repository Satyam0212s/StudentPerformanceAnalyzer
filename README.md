# Student Performance Analytics Dashboard

A Python-based analytics platform for processing and analyzing student academic performance.

## Features

- Student ranking system
- Mean, median, highest and lowest score analysis
- Pass/Fail analytics
- Performance categorization
- Subject-wise toppers
- Data visualization with Matplotlib
- SQLite database integration
- Interactive Streamlit dashboard

## Technologies

- Python
- Pandas
- NumPy
- SQLite
- Matplotlib
- Streamlit

## Run Locally

```bash
python main.py
